This is a simple 2d sidescroller game made on godot to help improve my gamedev skills
I sorta just add random game elements. I'm trying to make the game levels like the splatoon 3 story mode campaign with many types of levels


## Key gameplay elements:

- playable character with hoverboard-like physics 
- multiple levels (so far 2) with unique elements in each level
- a skin shop where you can customise your avatar by finding a special currency in each level
- bots that can kill you
- spinny wheel that can make you go woo
- a special "glitch" feature which essentially allows you to interact with all electrical objets (at least thats the idea, rn it's kinda useless except for a couple of gates)
- a battery that can recharge your health
- music and sfx
- settings for music and sfx

# How does it work?

Well most of the game is quite simple; you can think back to the older Mario games from the SNES era, using WASD to control the character, and future controller support planned, I wanted to add a little twist to the game, where if you press shift it'll enable a special gtich mode, allowing you to phase through walls temporarilly, think of it like the dash from celeste, except it recharges like a battey overtime instead of when you touch the floor.
